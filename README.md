# Armstrong Number in Java

## Description
This program checks whether a given number is an Armstrong number using Java. It extracts each digit, raises it to the power of the total number of digits, and calculates the sum.

## Example
Input: `153`

Calculation: `1³ + 5³ + 3³ = 153`

Output: `153 is an Armstrong Number`

## Concepts Used
- Java loops
- Conditional statements
- Arithmetic operators
- `Math.pow()`
- User input using `Scanner`

## How to Run
```bash
javac ArmstrongNumber.java
java ArmstrongNumber
```
